# Diagram prompts — Task 7 (v3, single-row layout)

**Why v3.** v1 and v2 asked for *six vertical lanes* carrying a *horizontal
flow*. The image model resolved that conflict by making each column follow the
chain instead — so `BLE → Phone App → Redpanda` landed in one column, MinIO
landed in the ingest column, and Metabase drifted into the model column. Three
generations failed identically.

v3 removes the conflict: **one horizontal row**, with the stage grouping shown as
pale background bands *behind* the boxes rather than as spatial containers. One
axis, nothing to reconcile.

Two other fixes from the failures:
- box count and numbering are explicit, so duplication has something to fail against
- the instruction (`EXACTLY ONE`) is no longer embedded inside a quoted label —
  that is what produced `LANE 3: RAW EXACTLY ONE`

**Save as:** PNG, white background →
`submission/images/task7_variant_a.jpeg` and `task7_variant_b.jpeg`.

Not under `submission/out/` on purpose: that directory is regenerated by the
pipeline, so `rm -rf out` (a legitimate clean-rebuild step) destroys anything
kept there that the code does not write itself.
